# 報告のひな形

## 表(これ1枚にまとめる)

```markdown
確かめた相手: <URL>(<何で確かめたか。例: ブラウザの道具 / width-check.mjs(Chrome)>)

| 画面 | 幅 | 横のはみ出し | はみ出す要素 | いちばん小さい文字 | 12px未満の文字 | 44px未満の押す所 | 文字と地の濃さの比 | 判定 |
|---|---|---|---|---|---|---|---|---|
| 縦 375×812・明 | 375px | 0px | 0 | 16px | 0 | 0 | 13.3 | OK |
| 縦 375×812・暗 | 375px | 0px | 0 | 16px | 0 | 0 | 14.0 | OK |

- 文字で確かめたこと: <見出し・ボタン・入力欄が出ているか。切れている言葉の有無>
- 画像で確かめたこと(1枚): <どの画面を見て、何が分かったか。見ていなければ「見ていない」>
- 直したほうがよい点: <なければ「なし」。あれば、要素・数値・理由>
- 未確認: 実機の iPhone(Safari の表示・ホーム画面への追加・指での操作)
```

上の数値は書き方の例。実際に測った値に置き換える。測っていない欄は空にせず「未確認」と書く。

## NG のときの書き方

はみ出しがあるときは、表の下に、要素と位置をそのまま書く。

```markdown
縦 375×812・明 ではみ出す要素: div.wide(左0〜右480)
```

直す案は、原因が数値から言える範囲だけにする(例: 「幅480pxの固定指定がある」)。確かめていない原因を言い切らない。

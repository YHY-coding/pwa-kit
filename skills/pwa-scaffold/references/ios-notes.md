# iPhone で起きやすいこと

**このページの内容は、実機で確かめたものではない。** 一般に知られている動きをまとめたもので、OS の版によって変わる。大事な点は、利用者の実機で確かめてから伝える。

| 起きること | 備え |
|---|---|
| ホーム画面に追加したあと、アイコンの絵を替えても、追加済みのアイコンは変わらないことがある | 替えるには、アイコンを消して追加し直す。**消すと保存したデータも消えるおそれがある**ので、先に「設定 → ファイルに書き出す」を案内する |
| ホーム画面に追加したアプリと、Safari で開いたページは、保存場所が別になることがある | 追加の前に入れたデータが、追加後に見えないことがある。追加してから使い始めるよう案内する |
| 長く開かないと、ブラウザが保存データを消すことがある | 定期的な書き出しを案内する。消えない約束はできない |
| 入力欄の文字が16px未満だと、触れたときに画面が拡大する | 入力欄は16px以上にする(雛形は18px) |
| 画面の上下に、切り欠きやホームの線がある | `viewport-fit=cover` と `env(safe-area-inset-*)` で余白を足す(雛形は対応済み) |
| 「ファイルに書き出す」の動き(保存先の選び方・ホーム画面に追加した状態での動き)は、版によって違う | 雛形には「写しを取る(コピー)」も付けてある。どちらが動くかは実機で確かめる |
| 新しい版に替わらない | `sw.js` の `CACHE` の番号を上げたかを `cache-check.py` で調べる。上げてあれば、開き直すと「新しい版があります」の帯が出る |
| `<dialog>`(設定の画面)は、古い iOS では動かない | 雛形は、動かないときに属性だけで開く代わりの動きを持つが、古い版での見え方は未確認 |

## このスキルで確かめられること・確かめられないこと

- 確かめられる: Chrome で、幅375px・通信なしで開くこと・はみ出しがないこと。
- 確かめられない: iPhone の Safari そのものでの表示、ホーム画面への追加、アイコンの見え方、書き出したファイルの保存。
